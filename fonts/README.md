# Optional stroke-font data

`futural.jhf` is the bundled Hershey face, obtained from:
https://github.com/kamalmostafa/hershey-fonts/blob/1356bf2f83d380fcef68c887e88675eb9d445d86/hershey-fonts/futural.jhf

The original data format and required acknowledgments/distribution terms are
preserved in HERSHEY-NOTICE.txt. These terms apply to the font data separately
from P1GL's GPL-3.0 code license. No libhersheyfont code is included.

The generator uses printable ASCII 32..126 (95 glyphs) and retains source data
for reproducibility. See generated/vector-font.json for the SHA256 and provenance,
and docs/G_VTEXT.md for the memory-bank allocation and API.
