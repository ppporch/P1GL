# Archived Type 30 backend — v0.8

This preserves the tested Type 30/Type 33 source and tests from commit a707fca.
It is not the default P1GL backend. Current development uses Type 340/342;
see ../../README.md. Historical module notes are in docs/.

On a Pi with pidp1-mods installed, `make all test` here runs the original v0.8
build and checks. Session-specific live loaders are historical development tools,
not generic installation commands. No automatically generated files or snapshots
are retained in Git. The parent repository's GPL-3.0 license applies.
